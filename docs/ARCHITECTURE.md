## Общий стейт (Redux)

### Где лежат редьюсеры
- `src/entities/skill/model/skillsSlice.ts`: слайс `skills` (загрузка, список, статусы).
- `src/entities/user/model/usersSlice.ts`: слайс `users` (загрузка, список, статусы).

### Как пользоваться (строго по правилам)
- **Не использовать** `useDispatch` / `useSelector` напрямую из `react-redux`.
- **Использовать** типизированные хуки из `src/store/hooks.ts`:
  
  `export const useAppDispatch = useDispatch.withTypes<AppDispatch>()`
  `export const useAppSelector = useSelector.withTypes<RootState>()`

## Подключённые слайсы в store

```typescript
export const store = configureStore({
  reducer: {
    skills: skillsReducer,
    users: usersReducer,
  },
})
```
Все слайсы (skills, users) подключаются в едином файле настройки стора: `src/store/index.ts`. Это гарантирует централизованное управление состоянием и предсказуемую структуру Redux.

## Селекторы (из слайсов)

- **`skillsSlice`:** `selectSkills`, `selectSkillsLoading`, `selectSkillsError`
- **`usersSlice`:** `selectUsers`, `selectUsersLoading`, `selectUsersError`

Эти селекторы экспортируются прямо из слайсов и предназначены для использования в компонентах.

## Правила импортов и нейминга
### Импорты: 
Все компоненты из `src/shared/ui` импортируются **только через публичный вход** — единый barrel-файл `src/shared/ui/index.ts`:

Импорты из остальных слоёв (`api, entities, features, store, shared`)  всегда через алиас `@/` (например, `@/entities/skill/model/skillsSlice`). Относительные пути вида `../../entities/...` между слоями запрещены.

### Компоненты: 
импортируются только из `@/shared/ui`. Это гарантирует, что используется единая реализация.
### Нейминг:
- Компоненты: `PascalCase (TextInput, Button)`.
- Пропсы: `camelCase`.
- Константы: `UPPER_CASE (ROUTES, SKILL_CATEGORIES)`.

## Константы (`src/shared/lib/constants.ts`)

- `ROUTES`: базовые пути и параметры роутинга.
- `SKILL_CATEGORIES`: категории навыков с подкатегориями. Используется для фильтров и отображения.
  - Типы: `Category, CategoryId, SubCategoryId`.
- `CITIES`: список городов для фильтрации и автодополнения.
  - Тип: `City`.
- `LOCAL_STORAGE_KEYS`: ключи для работы с localStorage.
Новые константы добавляются исключительно в файл `src/shared/lib/constants.ts` 
Не создавайте отдельные файлы констант в других слоях.

## Утилиты авторизации (`src/features/auth/model/authUtils.ts`)

Функции для работы с авторизацией и `localStorage`:

- `getAuthUser(): AuthUser | null` — читает текущего авторизованного пользователя из `localStorage`.
- `saveAuthUser(user: Omit<AuthUser, 'token'>): AuthUser` — сохраняет пользователя и mock‑токен в `localStorage`.
- `clearAuthUser(): void` — удаляет пользователя из `localStorage` (logout).

Все функции используют `LOCAL_STORAGE_KEYS.AUTH_USER` и корректно обрабатывают ошибки парсинга.

## Хуки и хелперы

### Хуки (`src/shared/hooks/`)

- `useDebounce<T>(value: T, delay = 300): T` — задержка значения для оптимизации запросов (поиск, фильтры).
- `useLocalStorage<T>(key: string, initialValue: T): [T, (val: T) => void]` — типизированная обёртка над `localStorage` с обработкой ошибок.

### Хелперы (`src/shared/lib/helpers.ts`)

#### Основные
- `formatDate(dateString: string): string` — форматирует дату в читаемый вид (ru‑RU).
- `truncate(str: string, maxLength: number): string` — обрезает строку до `maxLength` с многоточием.
- `generateId(): string` — генерирует уникальный ID через `crypto.randomUUID()`.
#### Дополнительные 
(используются в конкретных фичах, не являются базовыми).

- `getDeclension(count: number, words: readonly string[]): string` — склоняет слово по числу.
- `getAgeWithDeclension(birthDate: string): string` — вычисляет возраст и подставляет правильное склонение.

## Виджеты (`src/widgets/`)

Виджеты — это крупные самостоятельные блоки интерфейса, которые объединяют в себе UI-компоненты, фичи и данные из стора. Они не зависят от страниц и могут переиспользоваться.

* **`Header`** — Шапка сайта. Содержит логотип, навигацию, поиск, переключатель темы, уведомления и аватар пользователя.
* **`Footer`** — Подвал сайта с ссылками на разделы («О проекте», «Все навыки», «Контакты», «Политика конфиденциальности»).
* **`CatalogUserCard`** — Карточка пользователя в каталоге. Отображает аватар, имя, город, возраст, навыки («Может научить», «Хочет научиться»), кнопку «Подробнее» и иконку «Избранное».
* **`SkillInfoCard`** — Карточка навыка на странице навыка. Содержит галерею изображений, описание, категорию, теги, кнопку «Предложить обмен» и кнопки соцсетей.
* **`SimilarSkills`** — Карусель похожих предложений (пользователей, которые могут научить похожим навыкам). Реализована на базе `embla-carousel`.
* **`FiltersBar`** — Панель фильтров для каталога (категории, города, пол, формат обучения).
* **`NotificationStack`** — Стек всплывающих уведомлений (обернут в портал).

## Фичи (`src/features/`)

Фичи — это законченные пользовательские сценарии (действия), которые меняют состояние приложения.

* **`auth`** — Логика авторизации, регистрации и выхода. Включает хуки и утилиты для работы с токеном (`authUtils.ts`), а также компоненты форм (`LoginForm`, `RegisterForm`).
* **`catalog-filter`** — Логика фильтрации и поиска навыков в каталоге.
* **`exchange`** — Логика предложения обмена навыками (создание заявки).
* **`notifications`** — Логика управления уведомлениями (добавление, удаление, автоскрытие).
* **`registration`** — Пошаговая логика регистрации (выбор навыков, заполнение профиля).
* **`theme-switcher`** — Переключение светлой и темной темы оформления.
* **`like-user`** — Логика постановки и снятия лайков (избранного) с оптимистичным обновлением UI и синхронизацией с `localStorage` и Redux.

## Работа с API (Axios)

Все HTTP-запросы к серверу выполняются через единый экземпляр Axios, который находится в `src/shared/api/axiosInstance.ts`.

* **`baseURL`**: Настроен на `/api` (через `.env` или прокси Vite).
* **Перехватчики (Interceptors)**: 
  * **Request**: Автоматически добавляет заголовок `Authorization: Bearer <token>` к каждому запросу, если в `localStorage` есть токен. Если токена нет — заголовок не отправляется.
  * **Response** (опционально): Обрабатывает ошибку 401 (Unauthorized) для очистки устаревшего токена.
* Экспортируется через `src/shared/api/index.ts` для удобного импорта (`import { axiosInstance } from '@/shared/api'`).

## Слайсы (Redux)

Помимо `skills` и `users`, в проекте также используются следующие слайсы для управления специфичными состояниями:

* **`constructorSlice`** (`src/entities/constructor` или `src/entities/skill`) — Управляет конструктором обмена (добавление/удаление навыков для обмена, расчет стоимости/бонусов, если применимо).
* **`orderSlice`** — Управляет состоянием заказа (создание заказа, модальное окно успеха, статус загрузки).
* **`userSlice`** (`src/entities/user`) — Хранит данные авторизованного пользователя, статус проверки авторизации (`isAuthChecked`) и ошибки обновления профиля.

## Соглашения по коду (Code Style)

1. **Типизация:** Строго используем TypeScript, избегаем `any`. Для сложных структур создаем интерфейсы в `src/shared/types`.
2. **Стилизация:** Используем CSS-модули (`*.module.css`). Глобальные переменные (цвета, отступы) вынесены в `src/app/styles/global.css`.
3. **Тестирование:** Для компонентов пишем тесты с помощью `Jest` + `React Testing Library` (файлы `*.test.tsx`). Для сложных UI-компонентов используем `Storybook` (`*.stories.tsx`).
4. **Коммиты:** Следуем стандарту [Conventional Commits](https://www.conventionalcommits.org/ru/) (`feat:`, `fix:`, `docs:`, `test:`).
