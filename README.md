# SkillSwap

Платформа обмена навыками: пользователь рассказывает, чему может научить, находит людей с нужными ему навыками и предлагает обмен. Без денег, навык за навык.

> Командный проект курса «Фронтенд-разработчик» Яндекс Практикума (когорта 58).
> Оригинальный репозиторий команды: [PM-YandexPracticum/SkillSwap_58_1](https://github.com/PM-YandexPracticum/SkillSwap_58_1)

## Мой вклад

Каждая задача проходила полный цикл: отдельная ветка → Pull Request → код-ревью тимлида → merge в `develop`.

**UI-компоненты (`shared/ui`)**
- **Avatar** — переиспользуемый компонент аватара пользователя, покрыт тестами (Vitest + Testing Library).
- **Chip** — компонент-тег для навыков и категорий, покрыт тестами. Цвета вынесены в CSS-переменные (`--chip-*-bg`) для корректной работы в тёмной теме.
- **Skeleton** — заглушки на время загрузки данных; подключены при ленивой загрузке страниц (`RouterProvider`), проверке сессии (`SessionGate`) и в кнопке входа.

**Виджеты и фичи**
- **Header** — доработка шапки сайта (`widgets/Header`) по критериям приёмки.
- **Уведомления** — Redux-слайс и хук `useNotify` (`features/notifications`) для показа уведомлений из любой части приложения.
- **Заявки на обмен** — Redux-слайс с сохранением в `localStorage` и кнопка отправки заявки на странице навыка.

**Данные**
- **Справочник категорий и подкатегорий навыков**, на котором построены фильтры каталога.

## Возможности

- **Умный подбор** — «точные совпадения» и «рекомендации» на основе интересов и навыков пользователя
- **Фильтрация** — по категориям, навыкам, городам и форматам обучения
- **Личный кабинет** — профиль: чему могу научить, чему хочу научиться
- **Избранное** — сохранение понравившихся карточек
- **Обмены и уведомления** — заявки на обмен и оповещения о них
- **Светлая и тёмная тема**, скелетоны при загрузке, страницы ошибок

## Стек

- **React 18** + **TypeScript**
- **Redux Toolkit** — управление состоянием
- **React Router** — маршрутизация с ленивой загрузкой страниц
- **React Hook Form** + **Yup** — формы и валидация
- **Vite** — сборка и dev-сервер с proxy на API
- **Express** + **Multer** — мок-сервер API с загрузкой фото
- **Vitest** + **Testing Library** — тесты
- **Storybook** — документация UI-компонентов
- **ESLint**, **Stylelint**, **Prettier**, **Husky** — качество кода
- **GitHub Actions** — CI: линтинг, типы, тесты и сборка на каждый PR
- Архитектура — **Feature-Sliced Design**

## Как запустить

Нужен **Node.js 18.11+**. Проект запускается в **двух терминалах**.

**Терминал 1: мок-сервер API (порт 4000)**
```bash
cd server
npm install
npm run dev
```

**Терминал 2: фронтенд (порт 5173)**
```bash
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173).

> Если видна ошибка 500, проверьте, что сервер запущен и порт 4000 не занят другой программой (Windows: `netstat -ano | findstr :4000`).
